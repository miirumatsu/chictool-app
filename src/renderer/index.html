CHICTool User Guide

Use this guide while capturing and maintaining hardware inventory.

Getting started

  1. Sign in with your local CHICTool account. On a new installation, the first sign-in creates the first local user.
  2. Use Add User in the header to register another local user. The current signed-in user is shown beneath the app name and is recorded in inventory updates.
  3. Start each device from the Capture Computer Information section. Captured data is loaded for review first; it is not stored until you select Save.

Capture controls at a glance

Capture Computer Information

This is a reference illustration only. Use the controls in the main app to capture information.

Capture a local computer

  1. Under Capture Computer Information, leave Mode set to Local Computer.
  2. Select Capture. CHICTool reads the device information from the computer you are using.
  3. Wait for the status message to confirm that collection is complete. The collected serial number, hardware details, and hostname appear in Review and Save.
  4. Review the fields, complete the required values, then select Save.

Capture a remote computer

Before remote capture

  1. Ensure the target computer is powered on, connected to the network, and reachable by its hostname or IP address.
  2. Use an account that is permitted to connect to and collect information from the target computer.
  3. For a target not yet prepared for CHICTool, select Download Setup. Copy the script to the target, open PowerShell as an administrator, and run the script there.
  4. Return to CHICTool and select Trust Target. Administrator approval may be required because this updates the local computer's PowerShell trusted-host list.

The setup script uses a temporary execution-policy bypass only. It does not permanently change the target's execution policy.

  1. Choose Remote Computer from Mode. Enter the target hostname or IP address, username, and password.
  2. Select Ping first to confirm the target can be reached. Correct the hostname/IP address, credentials, network connection, or target setup if the test fails.
  3. Select Capture after Ping succeeds. The same review and save process applies to remote devices.
  4. The hostname and username are remembered for convenience; enter or update credentials as needed before collection.

Review and save the record

  1. Check the captured manufacturer, model, operating system, processor, storage, memory, GPU, MAC address, and hostname for accuracy.
  2. Enter organization-specific information such as Acquired On, Office, PAR Holder, Primary User, Other Details, and Remarks.
  3. Select a required Machine Type and Office. Required labels are marked with an asterisk.
  4. The collected Serial Number and Other Details are read-only. Use Serial Override when an alternate inventory serial is necessary.
  5. Use the ✦ button beside Model to remove non-alphanumeric characters from the beginning and end of the model value, when needed.
  6. Select Save only after review. Select Clear to discard the currently loaded form without changing saved inventory.

When an existing serial number is found

CHICTool asks which version to load. Select Load Captured to review newly collected hardware values alongside the existing record, or Load Saved to keep the stored values. Select Cancel if you do not want to change the form.

Find and manage inventory

  1. Use Search to find matching records by serial, hostname, model, office, or other saved text. Search also supports AND, OR, NOT, parentheses, and quoted phrases.
  2. Narrow the list with the Office and Device Type filters. Select sortable column headings to change the inventory order.
  3. Select Edit to load a saved device into the review form, make changes, then select Save.
  4. Select Delete to remove a device from active inventory. The record is retained for audit and future synchronization; linked peripherals become unlinked rather than deleted.

Manage peripherals

  1. Use the Peripherals section to add monitors, keyboards, mice, printers, and other equipment.
  2. Select a Linked Computer to associate an item with a computer, or leave it as Unlinked. Choose a Type, then enter the available manufacturer, model, serial number, asset tag, user, and remarks.
  3. Select Add to save the peripheral. Use the table's Edit action to revise an item or Delete to remove it from active inventory while retaining it for audit and synchronization.
  4. Use All, Linked, and Unlinked plus the peripheral search field to change the current view.

Export, backup, and audit

  1. Select Refresh Inventory to reload the inventory and lookup lists after changes.
  2. Select Export CSV and choose a save location to create a spreadsheet-friendly inventory export.
  3. Select Backup Database and choose a save location before major maintenance or as part of regular records protection.
  4. Select Audit Log to view recorded actions and the user who performed them.
  5. Reset Inventory permanently removes computers, peripherals, collection logs, and audit logs, while retaining lookup values. Back up the database first and use this only when intended.

Common capture issues

  • Remote Ping fails: confirm the hostname/IP address, network connection, credentials, and that the target is powered on.
  • Remote capture fails after Ping: run the target setup script as administrator, then trust the target from CHICTool and try again.
  • Save is unavailable: capture or load a record first, then ensure required fields such as Machine Type and Office are selected.
  • Wrong values loaded: select Clear and capture again, or load the saved record using Edit from Inventory.

Good inventory practice

Capture devices while they are connected to the expected network, verify the serial number against the physical label, consistently record the assigned user and office, and create a backup before a large batch of edits or a reset.
